## Por onde começar

Quem já usava o módulo antes da atualização deve ler **O que mudou** primeiro: ele mostra onde cada tela foi parar e traz a tabela de equivalência com a versão anterior.

Quem nunca montou um modelo começa por **Como criar um modelo**, e segue para **Um modelo, cinco canais** e **Os botões**, que são os dois assuntos onde a lógica mudou de verdade.

Quem administra a operação deve olhar **Quem pode ver e usar cada modelo**, por causa das seis permissões que nascem vazias nesta versão e precisam ser concedidas.

Quem cuida do resultado tem dois artigos: **A Visão geral**, para os números do catálogo inteiro, e **A tela do modelo**, para um modelo específico.
