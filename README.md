## Como o repositório está organizado

Cada módulo tem uma pasta própria, com um `README.md` que funciona como índice: a lista de artigos, a pergunta que cada um responde e por onde começar.

Nos módulos com vários artigos, cada artigo fica numa subpasta, com o texto no `README.md` e as imagens em `screenshots/`. O Consumo Meta é um artigo só, então o texto e as imagens ficam direto na pasta do módulo.

## Sobre as imagens

Os prints são capturados em janela de 1920 por 1080. As marcações em vermelho apontam o elemento comentado no texto ao lado. Nome, telefone e e-mail de terceiros são borrados ou ficam fora do recorte.
